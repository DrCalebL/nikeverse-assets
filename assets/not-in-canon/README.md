# Not in canon

Creature designs our games invented where no NFT art or canon reference existed (owner 2026-11-25).

Layout: `not-in-canon/<creature>/<game>/`, one folder per game that has a version of it.

- `echo/`, `sentinel/`, `hive/`
  - `deadwake/`: the first version. Deadwake (roguelike-nikeverse) drew these Retnuhxed in code from the Discord game DB
    rows; sheets approved by the owner 2026-09-29 (ledger `docs/art/APPROVALS.md`). `<creature>-sheet.png` is the
    code-drawn grey turnaround, `<creature>-compare.png` the 3D compare.
  - `fitness-game/`: the fitness game's version, a GPT Image 2.5 turnaround made from the Deadwake sheet in Fire's style
    (owner pick B, 2026-10-24): `<creature>-turnaround-approved.png` plus the cropped views
    `<creature>-{front,left,back,right}.png` that Tripo built the 3D model and rig from.
